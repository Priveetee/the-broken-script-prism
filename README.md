# The Broken Script

Pack minimal pour Prism Launcher.

- Minecraft 1.21.1
- NeoForge 21.1.249
- The Broken Script 2.0.4-hotfix

Dans Prism : `Ajouter une instance` puis `Importer depuis un fichier ZIP` ou une URL du fichier `.mrpack`.

Le mod doit être installé côté client et côté serveur. Cette archive ne contient pas de micro in-game.

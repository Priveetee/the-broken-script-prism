# The Broken Script

Pack minimal pour Prism Launcher.

- Minecraft 1.21.1
- NeoForge 21.1.249
- The Broken Script 2.0.4-hotfix
- Simple Voice Chat 2.6.23 (obligatoire)

Dans Prism : `Ajouter une instance` puis `Importer` une URL du fichier `.mrpack`.

Le mod doit être installé côté client et côté serveur. Serveur : `eltux.fr:31887`, voix : `31868/udp`.
